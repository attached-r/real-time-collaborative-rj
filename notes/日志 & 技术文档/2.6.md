## 今日关键代码片段

### DocumentController - 创建文档

```java
@PostMapping
public ResponseEntity<Map<String, String>> create(@RequestBody Map<String, String> request) {
    String title = request.get("title");
    String content = request.get("content");

    DocumentEntity doc = documentService.create(title, content);

    return ResponseEntity.ok(Map.of("id", doc.getId(), "message", "创建成功"));
}
```

### DocumentController - 获取详情（带权限）

```java
@GetMapping("/{id}")
public ResponseEntity<DocumentEntity> getDocumentById(@PathVariable String id) {
    Optional<DocumentEntity> optionalDoc = documentService.getById(id);

    if (optionalDoc.isEmpty()) {
        return ResponseEntity.notFound().build();
    }

    DocumentEntity doc = optionalDoc.get();

    String currentUserId = (String) SecurityContextHolder.getContext().getAuthentication().getPrincipal();

    if (!doc.getOwnerId().equals(currentUserId)) {
        return ResponseEntity.status(403).build();
    }

    return ResponseEntity.ok(doc);
}
```

### DocumentController - 列表（自动过滤）

```java
@GetMapping
public List<DocumentEntity> getDocuments() {
    String userId = (String) SecurityContextHolder.getContext().getAuthentication().getPrincipal();
    return documentService.listByUser(userId);
}
```

## 信息技术学习点：Spring Security 在 Controller 中的使用 & 权限控制

- **SecurityContextHolder**：线程本地存储当前请求的认证信息（Authentication）
  - `getAuthentication()`：获取当前用户认证对象
  - `getPrincipal()`：主体（当前返回 UserDetails 或 String）
  - 作用：让 Controller/Service 无需传参就能知道“当前用户是谁”
- **权限控制方式**：
  - 方法级：`@PreAuthorize("hasRole('ADMIN')")` 或自定义注解（后期加）
  - 代码级：手动 if 判断 ownerId（当前方式，简单灵活）
  - 配置级：SecurityConfig .authenticated() / .permitAll()
- **重要对象**：
  - Authentication：当前认证信息（principal、authorities、isAuthenticated）
  - UserDetails：用户详情（用户名、密码、权限列表）
  - ResponseEntity：统一返回 HTTP 状态 + body（404/403/200）
