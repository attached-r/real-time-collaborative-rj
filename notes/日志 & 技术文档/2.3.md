## 今日关键代码片段

### JwtTokenProvider.generateToken 示例

```java
public String generateToken(Authentication authentication) {
    String username = authentication.getName();
    Date now = new Date();
    Date expiryDate = new Date(now.getTime() + jwtExpirationMs);
    return Jwts.builder()
            .subject(username)
            .issuedAt(now)
            .expiration(expiryDate)
            .signWith(getSigningKey())
            .compact();
}
```

### AuthController.login 示例

```java
@PostMapping("/login")
public ResponseEntity<?> login(@RequestBody Map<String, String> request) {
    String username = request.get("username");
    String password = request.get("password");
    Authentication authentication = authenticationManager.authenticate(
            new UsernamePasswordAuthenticationToken(username, password));
    SecurityContextHolder.getContext().setAuthentication(authentication);
    String token = jwtTokenProvider.generateToken(authentication);
    return ResponseEntity.ok(Map.of("token", token));
}
```

### CustomUserDetailsService.loadUserByUsername 示例

```java
@Override
public UserDetails loadUserByUsername(String username) throws UsernameNotFoundException {
    User user = userRepository.findByUsername(username)
            .orElseThrow(() -> new UsernameNotFoundException("用户不存在: " + username));
    return new org.springframework.security.core.userdetails.User(
            user.getUsername(), user.getPassword(), Collections.emptyList());
}
```

## 信息技术学习点：Spring Security 的实现机制 & 重要对象/方法

### Spring Security 核心机制
- **认证 (Authentication)**：验证用户是谁（用户名/密码/token）。核心是 AuthenticationManager，它协调多个 Provider（像 DaoAuthenticationProvider）处理不同认证方式。
- **授权 (Authorization)**：验证用户能做什么（权限/角色）。基于 Authentication 对象里的 authorities。
- **无状态 JWT 机制**：用 token 代替 session，Filter 每请求解析 token 恢复 Authentication，不存服务器。
- **流程链**：HttpSecurity 配置过滤链（如 JwtFilter 在 UsernamePasswordAuthenticationFilter 前），每个请求都走链条（拦截、认证、授权）。

### 重要对象 & 方法
- **Authentication**：表示用户认证信息。重要方法：
  - `getName()`：获取用户名
  - `getAuthorities()`：获取权限列表
  - `isAuthenticated()`：是否已认证
- **AuthenticationManager**：认证入口。方法：
  - `authenticate(Authentication token)`：输入待验证 token，返回已认证对象或抛异常
- **UserDetails**：用户详情接口（你的 CustomUserDetailsService 返回它）。方法：
  - `getUsername()` / `getPassword()`：用户名/密码
  - `getAuthorities()`：权限
- **UserDetailsService**：加载用户接口。方法：
  - `loadUserByUsername(String username)`：查数据库返回 UserDetails
- **PasswordEncoder**：密码加密接口。方法：
  - `encode(String rawPassword)`：加密明文
  - `matches(String rawPassword, String encodedPassword)`：比对明文 vs 加密

这些对象让 Security 解耦：你只需提供数据源（Repository），Security 自动处理校验/异常。
