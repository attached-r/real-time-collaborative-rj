## 今日关键代码片段

### DocumentEntity 实体核心

```java
@Data
@Document(collection = "documents")
public class DocumentEntity {
    @Id
    private String id;
    private String title;
    private String content;
    private String ownerId;
    @Version
    private Long version;
    private List<DocumentVersion> versions = new ArrayList<>();
    @CreatedDate
    private LocalDateTime createdAt;
    @LastModifiedDate
    private LocalDateTime updatedAt;
}
```

### DocumentService.create 方法

```java
public DocumentEntity create(String title, String content) {
    Authentication auth = SecurityContextHolder.getContext().getAuthentication();
    if (auth == null || !auth.isAuthenticated() || "anonymousUser".equals(auth.getPrincipal())) {
        throw new IllegalStateException("请先登录");
    }
    String ownerId = (String) auth.getPrincipal();

    DocumentEntity doc = DocumentEntity.builder()
            .title(title)
            .content(content)
            .ownerId(ownerId)
            .version(null)  // 避免乐观锁冲突
            .versions(new ArrayList<>())
            .build();

    return documentRepository.save(doc);
}
```

### DocumentRepository 自定义查询

```java
public interface DocumentRepository extends MongoRepository<DocumentEntity, String> {
    List<DocumentEntity> findByOwnerId(String ownerId);
}
```

## 信息技术学习点：Spring Data MongoDB 乐观锁 & 实体保存机制

- **@Version 乐观锁机制**：Spring Data MongoDB 使用 version 字段实现“先查后改”防并发覆盖。save() 时自动：
  - 新实体：version=null → 生成 ObjectId 并设 version=1
  - 更新实体：version 匹配则 +1，否则抛 OptimisticLockingFailureException
- **难点**：新实体 id=null + version=0 会导致查询条件失效 → 报 "Could not obtain identifier"
- **解决**：新文档 version 设 null，或用 mongoTemplate.save() 绕过
- **SecurityContextHolder**：线程本地存储认证信息，Filter 解析 token 后 setAuthentication，后续 Service/Controller 随时 getPrincipal() 拿用户标识，无需传参
- **重要对象**：
  - MongoRepository：自动 CRUD + 自定义查询（findByXxx）
  - MongoTemplate：底层操作模板，手动 save 绕过乐观锁
  - SecurityContextHolder：获取当前 Authentication（principal、authorities）
